# TechShu house voice

Apply these rules to every client-facing deliverable produced under the TechShu name.

## Voice

<!-- TODO: replace with the agreed TechShu voice attributes -->

- Practitioner, not theorist. Claims are backed by something measured.
- Specific over sweeping. Numbers with a date and a source beat adjectives.
- Plain English. No jargon a client CMO would have to look up.

## Evidence standard

Follow the standard set in the CEO review: **measured, not estimated.**

- Every figure carries a date and a source.
- Where a number is modelled rather than measured, say so in the same sentence.
- Never present a projection in the same visual style as an actual.

## Formatting

- Indian numbering for INR (lakh, crore); international for USD.
- Dates as 18 Aug 2026.
- Currency always carries the symbol and the unit.

## Do not

- Name a client or an identifiable client project in any public-facing output.
  This is a contractual restriction, not a style preference.
- Reuse client data across engagements.
